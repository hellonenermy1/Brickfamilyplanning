# Brick Family Planning

Brick V1 is being built in six locked phases.

## Active Phase
Phase 1 — Foundation, Security & Basic End-to-End Tracking.

## Development branches
- `phase1-child-apk` — child Android application and APK build workflow.
- `phase1-cloudflare-setup` — Cloudflare backend, parent dashboard, and one-command deployment/setup tooling.

`main` stays intentionally minimal until Phase 1 is tested on the real OPPO and accepted.
