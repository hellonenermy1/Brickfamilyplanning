## Source gap and bounded delivery

The existing controller API enrolled one object per call. The focused test reproduces the failure pattern: owner A enrolls, owner B already belongs to another controller and throws, owner C remains unconfigured. Legacy single-owner calls remain available for compatibility; blindly looping them is not an atomic runtime setup.

`installStagedCaptureWriterControllers` now provides one synchronous bounded enrollment of up to64 distinct owners. It snapshots the owner list and materializes/validates the controller before any registry write. Existing or invalid targets, duplicate owners and controller errors refuse the whole new group. It rechecks conflicts after capability getters/bindings are materialized so reentrant enrollment cannot be overwritten. No asynchronous or network work occurs inside this local boundary. Foreign/preexisting enrollment is preserved; there is no uninstall, takeover or implicit rollback.

`createStagedRuntimeCaptureInstaller` is a private in-isolate source capability for one logical owner plus both raw D1 object bindings. It requires scope, descendant, reservation/start/cancel/exit, notice and urgent-quarantine methods; snapshots method references/timeout; rejects missing/aliased/malformed binding objects; and enrolls new members together. The same installer can idempotently reuse its own resource objects or add another actor. A foreign registration refuses before configuring new members, and an already enrolled logical owner cannot switch database references. The input implementation's own mutable state remains trusted caller responsibility.

The inherited D1 scope and urgent/outage authorization logic are unchanged. The installer does not mint scope, inspect secrets, initialize authority/replay/guard state, create a client, choose endpoint/epoch/resource identity, expose a route, schedule work or return a permission/quiescence receipt. Arbitrary shape-valid callbacks are not proof of authenticated clients or independent quarantine. A real trusted caller must provide verified signed clients and independently reviewed bindings.
