# Phase 5 Scope Guard

Phase 5 may implement source and hosted tests while earlier physical OPPO acceptance remains open.

It must not:
- mark Phase 2/3/4 DEVICE_VERIFIED without physical evidence;
- replace fused location as the primary normal source;
- treat RSSI as exact distance;
- expose internal weights as calibrated probabilities;
- overwrite raw or original realtime estimates during refinement;
- make unsupported ranging hardware a required dependency;
- create a public crowdsourced tracking network;
- merge into canonical runtime branches before the Phase 5 gate is reviewed.
